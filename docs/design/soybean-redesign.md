# 波波公考蓝紫学习工作台改版

用户已选择 Soybean 风格。参考：[SoybeanAdmin Element Plus](https://github.com/soybeanjs/soybean-admin-element-plus)，MIT；[参考图](soybean-reference.png)来自官方 README 示例。示例可能与当前演示版本有差异。本次参考视觉，不整体移植后台模板。

## 已确定的设计

- 色彩：主色 `#646cff`，主色浅底 `#eeefff`，页面 `#f7f9fc`，白色面板 `#ffffff`，正文 `#273044`，次级文字 `#8491a5`，细边框 `#edf0f6`。
- 布局：桌面白色左导航与顶栏；欢迎区、四项彩色真实统计、答题趋势与科目分布、快速入口与社区动态。移动端使用抽屉与底部导航，所有既有页面仍可访问。
- 字体：中文使用系统微软雅黑/苹方，正文 14–16px，题干和材料 16px、较宽行距；标题 24–28px，数据使用等宽数字。
- 组件：12px 圆角白面板、8px 圆角按钮、淡蓝紫选中项、轻阴影、现有 Element Plus 图标。彩色统计卡是主要视觉特征，其余区域保持安静。
- 内容：保留“波波公考”、考生/管理员登录、模块刷题、模拟考试、申论、错题、收藏、学习社区、学习统计及考试记录。新增首页图表和动态使用已有只读接口中的真实数据。
- 交互：保留现有认证、校验、作答、交卷、评分和社区逻辑；键盘焦点可见；减少动画偏好生效。

## 对参考的有意调整

参考的销售、访问量、下载量改为现有答题、正确率、已交卷考试与待复习错题；不展示虚构增长率。参考的后台系统菜单和标签页改为考生学习导航；首页额外显示既有练习入口。登录和注册延续同一蓝紫主题。

内置 Image Gen 在当前会话未提供，因此以用户选定的现成完整参考图作为视觉依据，直接实现真实 Vue 页面；未调用需要额外凭据的生图 API。

使用内置浏览器验证 `http://localhost:7001/`，桌面默认视口 1280×720、手机 390×844；最后恢复默认视口。参考源图为 4050×2716，未按源图像素尺寸复刻，因为本次采用风格并保留项目真实学习内容。浏览器截图保存在 `docs/screenshots/soybean-*.png`。

已用 `view_image` 同时检查参考图、最终桌面首页和手机首页，并检查登录页。对照结果：

| 对照项 | 参考与最终页面 | 修正或有意调整 |
| --- | --- | --- |
| 布局 | 白色左栏、白顶栏、欢迎区、四张彩色统计卡、左右图表及下方内容区 | 后台多标签导航改为真实学习导航；手机改抽屉与底栏 |

| 动态效果 | 轻量选中/悬停变化 | 图表及CSS均尊重减少动态效果偏好；侧栏变化触发图表容器尺寸观察 |

首屏文案核对：品牌、菜单和主要学习入口来自既有功能；新增“社区动态”、日期和图表标题均对应实际内容。没有添加虚构成绩、增长率或学习时长。整体已按用户选定风格进行忠实适配，以上功能与对比度调整是有意差异，无待修的可见布局问题。
